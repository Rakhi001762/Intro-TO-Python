About Python

Python is a programming language: a way to give a computer clear instructions. You write short lines of text, and Python runs them from top to bottom. You don’t need any earlier coding experience to start.

Who made it

Guido van Rossum created Python, and it was first released in 1991.

Where the name comes from

It is named after the comedy show Monty Python’s Flying Circus, not the snake.

Why it is easy

Simple words, no semicolons, and indentation that shows how your code is organized.

What you can build

Websites, games, data charts, automation scripts and AI tools.

Variables, loops and functions

These three ideas appear in almost every Python program. Change the values and watch the code and output update.

Variables: names that store values

Use = to store a value under a name. You can then use that name in calculations and in print().

Loops: repeat without copying code

A for loop runs a fixed number of times. A while loop keeps going as long as its condition is true, so it must change a value (like i += 1) to finish.

Functions: reusable blocks of code

A function is defined once with def and then called as many times as you like. return sends the result back to the line that called it.

Graph: how a power function grows

Python makes it easy to compute lists of values and plot them. Move the slider to change the exponent n in y = x ** n.

xs = [i / 10 for i in range(-30, 31)]
ys = [x ** n for x in xs]
